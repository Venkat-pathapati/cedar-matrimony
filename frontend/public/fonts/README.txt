GILL SANS EXTRABOLD
-------------------
The website's font is  font-family: "Gill Sans Extrabold", sans-serif;
Gill Sans is a licensed font (Monotype), so it cannot be loaded from Google Fonts.

To make it appear for EVERY visitor, put your licensed copy in this folder with one of these names:
    GillSans-ExtraBold.woff2      (best)
    GillSans-ExtraBold.ttf
Nothing else needs to change - app/globals.css already points here.

Without a file, it is shown only on devices that already have "Gill Sans Extrabold" installed;
everyone else sees the browser's normal sans-serif.
